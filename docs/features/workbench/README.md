# Workbench experience

This category documents fork-specific desktop interaction defaults. The features keep decisions explicit and keyboard reachable while reducing unsolicited startup, recommendation, experiment, survey, and release-note surfaces.

## Features

- [Keyboard-first dialog notifications](keyboard-first-dialogs.html) — present desktop dialog decisions as actionable notifications and collect text through Quick Input.
- [Quiet defaults](quiet-defaults.html) — start new profiles with fewer automatic welcome, recommendation, experiment, survey, release-note, and restricted-mode surfaces.

These features do not expose an HTTP API, so a category Postman collection is not applicable.
