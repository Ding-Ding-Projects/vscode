# Integrations

Fork-specific integrations are documented here. Each integration must remain opt-in, preserve the repository selected by the user, and report launch failures through accessible, non-blocking workbench notifications.

## Features

- [Desktop Material](desktop-material.html) — open the selected Git repository in Desktop Material from the Command Palette or Source Control menus.

No integration in this category exposes an HTTP API, so a category Postman collection is not applicable.
